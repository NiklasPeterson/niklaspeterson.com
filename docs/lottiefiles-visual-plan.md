# LottieFiles Portfolio Visual Plan

## Goal

Create a focused visual narrative for each LottieFiles case study using original product screens, recordings, and custom compositions. Every visual should prove a specific part of the written story rather than repeat the landing-page artwork.

## Visual principles

- Use original product work whenever possible.
- Show one clear idea per visual.
- Lead with complete product views, then use tighter crops for supporting details.
- Use full-width visuals for overviews, important workflows, and cross-tool stories.
- Use 50/50 visuals for comparisons, related details, or two states of the same workflow.
- Keep captions to one short sentence written in past tense.
- Avoid invented metrics, generic code imagery, and marketing visuals that did not represent the product work.
- Anonymize private customer, team, and asset information before export.
- Prefer still images for detailed interfaces and short videos for interactions or state changes.

## Capture and export specifications

### Still images

- Capture at 2x resolution when possible.
- Export as PNG for interface screenshots.
- Use a consistent browser or application frame only when it helped explain context.
- Keep full-width compositions close to 16:9.
- Keep paired 50/50 visuals at the aspect ratio selected for that pair, usually 16:12.
- Leave enough surrounding space for the existing rounded crop and subtle border.

### Videos

- Record only the interaction needed to explain the feature.
- Target 8 to 20 seconds for focused interactions.
- Remove idle time at the beginning and end.
- Export as optimized MP4 with a matching poster image.
- Avoid cursor movement that did not contribute to the story.
- Keep sensitive information out of the recording area.

### File naming

Use lowercase descriptive names:

`lottiefiles-[project]-[visual]-2026.png`

`lottiefiles-[project]-[visual]-2026.mp4`

Examples:

- `lottiefiles-dam-mixed-format-library-2026.png`
- `lottiefiles-motion-system-publishing-2026.mp4`
- `lottiefiles-handoff-react-ios-comparison-2026.png`

1. Digital Asset Management
2. Motion Systems
3. Developer Handoff

5. Final consistency and quality review
