# LottieFiles Motion System Visual Notes

## Purpose

Preserve the visual recommendations from the Motion System review so they could be incorporated into the main LottieFiles portfolio visual plan.

## Source material reviewed

- Long Motion System overview capture supplied in the side conversation.
- Existing portfolio video: `public/lottiefiles-motion-system.m4v`
- Existing video poster: `public/lottiefiles-motion-system-poster.png`
- [LottieFiles Motion System landing page](https://lottiefiles.com/motion-system)

## What the long overview capture covered

The overview screen contained:

- Motion System title and published state
- Living documentation and motion principles
- Approved logo, illustration, brand, and marketing assets
- Colors
- Fonts
- Easing curves
- Motion presets

The complete tall screenshot should not be used as a single portfolio visual because its individual sections would become too small to read. It should be split into focused crops or used as the source for a curated composition.

## Visuals that could be completed from the overview

### 1. Motion System overview

Create a full-width composition containing:

- System title and published state
- Documentation
- A representative selection of approved assets
- Colors and fonts
- Easing and motion presets

Caption:

> Brought motion standards into one shared source of truth.

### 2. Easing

Crop the Easing section into a dedicated 50% visual.

Caption:

> Made approved easing curves easier to discover and reuse.

### 3. Motion presets

Crop the Motion Presets section into the matching 50% visual.

Caption:

> Turned recurring interactions into reusable motion presets.

The Easing and Motion Presets visuals should form a 50/50 row.

### 4. Living documentation

Use the documentation section as part of the main overview or as a supporting visual showing that principles and guidance lived beside the assets they governed.

Caption:

> Kept motion principles and reusable resources in the same system.

### 5. Approved asset library

Use selected logo, illustration, brand, and marketing asset sections to show that approved assets lived alongside the system standards.

Caption:

> Connected approved assets with the standards that guided their use.

## Visuals only partially covered

### Publishing and versioning

The overview header showed a published state, a version label, Unpublish, and Edit System controls. This supported the idea of governance but was not strong enough for a standalone publishing visual.

A dedicated capture should ideally show one or more of:

- Publishing confirmation
- Draft changes
- Version history
- Previous versions
- Permissions
- Governance controls
- An update being published

## Visuals still missing

### Motion tokens

Colors and fonts were visible, but the overview did not show motion-token names, values, modes, or editing controls clearly enough to complete this part of the story.

### Available across tools

The existing portfolio video and poster focused on the Workspace and Platform experience. They supported the source-of-truth story but did not clearly prove that the system was available inside Lottie Creator, Figma, or After Effects.

The Motion System landing page contained the most relevant material in its **From source of truth to shipped product** section:

- Workspace: source of truth
- Lottie Creator: author and apply
- Figma and After Effects: produce and consume
- Code: roadmap

The Code roadmap view should not be included in the portfolio composition because it could imply that runtime integration had already shipped.

## Recommended cross-tool composition

Create one full-width visual that connected three product views:

1. **Workspace**
   - Use the supplied Motion System overview or a focused Platform crop.

2. **Lottie Creator**
   - Show tokens, easing, or presets available beside the canvas.

3. **Figma and After Effects**
   - Show the plugins pulling from or applying the same system.

Present the sequence as:

`Workspace -> Lottie Creator -> Figma + After Effects`

The visual should communicate movement from a governed source of truth into the tools where motion was authored and consumed. It did not need to reproduce the landing-page layout.

Caption:

> Carried the same motion standards into the tools teams already used.

## Recommended Motion System visual set

1. Curated Motion System overview, full width
2. Easing, 50%
3. Motion presets, 50%
4. Living documentation and approved assets, full width or short recording
5. Publishing and versioning, full width when a stronger source became available
6. Workspace to Creator to Figma and After Effects composition, full width
